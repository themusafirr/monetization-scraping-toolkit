## 🌟 Modules & Products

### 1. 🗺️ Automated Travel Itinerary & Budget Guide Engine
- **Engine:** `travel-itinerary/itinerary_generator.py`
- **Output:** Publication-ready, responsive HTML travel guides and high-resolution (1080×1920) social media carousels.
- **Included Destinations:** Pushkar, Udaipur, Jaipur (extensible to any global destination).
- **Features:**
  - Day-by-day curated morning/afternoon/evening schedule.
  - Comprehensive itemized budget calculator (Hotels, Food, Transport, Activities).
  - Built-in UPI instant QR payment integrations and social CTA anchors.

### 2. 🤖 Local Business Bot Blueprints
- Client conversion templates for restaurants, gyms, and retail stores.
- Automated table reservation and order intake bots.

### 3. 📊 High-Converting Promo Poster Generator
- Programmatic HTML-to-Image rendering pipeline producing 1080×1080 Instagram feed posts and 1080×1920 stories.

## 🚀 Quick Start

### 1. Run Itinerary Generator
```bash
cd travel-itinerary
# Generate full guide for Pushkar
python3 itinerary_generator.py pushkar

# Generate full guide for Udaipur
python3 itinerary_generator.py udaipur

# Generate full guide for Jaipur
python3 itinerary_generator.py jaipur
```

### 2. View Generated Artifacts
Generated guides will be saved in `previews/` as standalone, self-contained HTML files with embedded styling.
